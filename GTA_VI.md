# GTA VI Rich Presence preset

This guide deploys the included `presets/gta6.json` profile. Follow [README.md](README.md) for the general installation and systemd hosting instructions.

## Included activity

| Field | Value |
| --- | --- |
| Game name | Grand Theft Auto VI |
| Activity type | PLAYING |
| Application ID | `1572964622938542150` |
| Large image asset ID | `1572964991118741646` |
| Asset name | `largeimage` |
| Details / state | Not set |
| Platform hint | `ps5` |
| Elapsed timer | Enabled |
| Refresh interval | 3 minutes |
| Initial start timestamp | `2026-11-13T20:49:16+07:00` |

The application ID and image asset are public identifiers from the author's Discord application; other installations can use the supplied IDs as long as the application and asset remain available. They do not grant access to the author's Discord account. Change the IDs if you want to maintain your own assets.

The `ps5` field is only a platform hint for Rich Presence. The official **Playing on PlayStation** header and icon are generated by Discord's PlayStation Network integration, not by this selfbot. This preset does not guarantee that exact appearance.

## Activate GTA VI

After installing dependencies and creating your private `.env` file:

```bash
npm run preset:gta6
npm start
```

For an existing systemd service, replace `npm start` with:

```bash
systemctl --user restart discord-rich-presence-selfbot.service
```

## Change the elapsed play time

The field `elapsedStartAt` represents the **start time**. Discord computes elapsed time from it. The supplied timestamp is a snapshot; it is not always dynamically six days behind the current time.

Set the timer to **6 days ago from the moment you run the command**:

```bash
node time.js gta6 days 6
node preset.js gta6
systemctl --user restart discord-rich-presence-selfbot.service
```

Set the timer to **10 hours ago**:

```bash
node time.js gta6 hours 10
node preset.js gta6
systemctl --user restart discord-rich-presence-selfbot.service
```

Set a **specific start date and time** (ISO 8601 with time-zone offset):

```bash
node time.js gta6 at 2026-11-13T20:49:16+07:00
node preset.js gta6
systemctl --user restart discord-rich-presence-selfbot.service
```

Alternatively, edit the `elapsedStartAt` value in `presets/gta6.json` manually, then re-apply the preset and restart the service.

The timer continues to count upward and retains its start time after restarts. If you change the `elapsedStartMode` to `session`, remove `elapsedStartAt` to have the timer start on each process launch. Setting `showElapsed` to `false` hides the play timer.

## Change the image or display text

Update `applicationId`, `largeImage`, `largeText`, `details` or `state` in `presets/gta6.json`. The supplied asset is already registered as `largeimage` under the included Application ID.

`details` and `state` are intentionally `null`. Leave them unset if you only want the game name and elapsed timer. Set `refreshMinutes` to `0` to disable periodic re-application.

Run `node preset.js gta6` and restart your running process or service after changes.
